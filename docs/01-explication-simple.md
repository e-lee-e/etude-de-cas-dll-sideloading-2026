# L'incident expliqué simplement

L'ordinateur a été piraté quand un fichier reçu comme une « image » a été ouvert. Ce n'était pas une image mais un programme. Il a installé deux logiciels espions, restés actifs trois jours et demi.

## Une image pour comprendre

Un livreur vous remet un colis. En l'ouvrant, vous laissez entrer sans le savoir quelqu'un qui fait un double de vos clés. Il revient ensuite chaque fois que vous rentrez chez vous, regarde ce que vous faites et peut emporter ce qu'il veut. Le lendemain, il fait entrer un complice par une autre porte.

## Ce que les pirates ont pu faire

- Lire les mots de passe et les sessions ouvertes dans les navigateurs.
- Accéder aux comptes sans connaître les mots de passe, même protégés par un code SMS, tant que la session était ouverte.
- Voir les fichiers et ce qui se passait à l'écran.

## Pourquoi l'antivirus n'a rien vu

Les pirates ont utilisé de vrais programmes, signés par de vrais éditeurs, pour faire tourner leur code caché. C'est une technique conçue pour passer sous les radars. Le fichier piégé, lui, était fait pour ressembler à une simple image.

## Après le nettoyage

Les deux logiciels espions sont arrêtés et ne peuvent plus contacter leurs auteurs. En revanche, personne ne peut reprendre les doubles de clés déjà faits : les mots de passe et les sessions doivent être considérés comme connus des pirates.

## Ce que la victime doit faire

Dans l'ordre, et depuis un autre appareil que le PC touché :

1. Changer le mot de passe de la messagerie principale et choisir « déconnecter tous les appareils ».
2. Faire de même pour les comptes bancaires et financiers, puis vérifier les opérations récentes.
3. Faire de même pour tous les comptes ouverts dans un navigateur du PC.
4. Activer la double authentification par application, pas par SMS.
5. Retrouver qui a envoyé le fichier et prévenir cette personne : son compte est probablement piraté lui aussi.
6. Sauvegarder les documents personnels, puis faire réinstaller Windows.
